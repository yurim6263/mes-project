2. 불량 LOT에서 역추적해 자재 LOT(릴·솔더)·설비·시각 찾기
3. 설비 통신 끊김 후 복구돼도 실적 중복·누락 없음
4. 수량 정정 시 사유 필수, 이전 값 이력 보존
